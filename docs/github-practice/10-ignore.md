# 忽略本地产物

`.gitignore` 控制未跟踪文件的忽略规则。它不会自动停止跟踪已经提交的文件。

## 示例

```gitignore
.DS_Store
__pycache__/
.venv/
```

这些只是常见示例，应根据项目调整。项目需要交付的图片、数据或锁文件，不应该因为文件较大或自动生成就一律忽略。

## 练习

在自己的练习仓库创建一个应忽略的临时文件，用 `git check-ignore -v PATH` 查看匹配规则，将 PATH 替换为真实路径。

## 完成时核对

必要源码和交付物仍可见。忽略规则不是秘密保护机制；已经泄露的凭证需要撤销或轮换。

参考：[Git ignore](https://git-scm.com/docs/gitignore)。
