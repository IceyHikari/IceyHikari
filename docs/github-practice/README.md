# GitHub 操作练习

这是一套由 Codex 整理的中文参考笔记，按主题通过独立 PR 加入个人仓库，用于练习分支、提交和合并，也用于推进 Pull Shark 成就。它们不是课程项目成果，也不表示我已经亲手执行过每条示例命令。

所有命令示例都应在自己拥有的练习仓库中使用。将 YOUR-REPO 和分支名替换为实际值，先查看状态再操作。
